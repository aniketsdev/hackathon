# Hackathon Plan for 2 People

## Team
- Person 1: UI, product, pitch, demo
- Person 2: scanner, API, GitHub integration

## Hour 1: Setup
- Create GitHub repo
- Push starter kit
- Run locally
- Create branches:
  - `feat/ui-dashboard`
  - `feat/agent-backend`

## Hour 2-3: Core Build
Person 1:
- Polish dashboard
- Add branding
- Improve findings cards

Person 2:
- Improve scanner
- Add PR comment generation
- Add optional GitHub API posting

## Hour 4: Integration
- Merge branches into `demo`
- Test scan flow
- Fix build errors

## Hour 5: Demo Polish
- Create vulnerable PR
- Prepare fallback local demo
- Write final pitch

## Final 90 Minutes
No major new features.
Only bug fixes, demo script, and presentation.

## Rule
A working simple demo beats an unfinished complex platform.
